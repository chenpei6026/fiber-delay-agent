# 复现与答辩提纲

1. 为什么 t=Ln/c？折射率 n=c/v，所以光纤群速度 v=c/n，传播时间 L/v=Ln/c。1000km、n=1.468 约4.897ms单程。
2. 为什么 RTT 不能直接除以二当作测量单程？正反向路由和排队可能不同；本项目的2t仅是对称路径假设下的传播基线。
3. 三个 Tool 是否写死原因？没有。查询工具返回指标、计算工具返回数值、阈值工具返回比较结果；原因分析由证据归纳层提出候选解释。
4. LLM 具体干了什么？根据自然语言和请求字段决定 diagnose/calculate/service/clarify 意图，并选择工具列表。C7仅算传播，C8仅查业务；不是每题固定调用全部工具。
5. 为什么不让0.6B模型写最终数字？课堂材料已经提到小模型歪曲工具结论，故本项目把结果数值和证据归纳锁在可审计程序里。对照收益属于整个工程系统，不能全归因于“模型更聪明”。
6. 高利用率证明拥塞吗？不能。94%只能支持负载竞争假设，需同时段队列、错误计数、路径与RTT时间序列排查。
7. 什么情况增加带宽无效？传播下限本身超预算；增加带宽不能提升传播速度。
8. FMISSING 为什么不直接判拥塞？缺长度，不能计算传播基线；即使利用率高仍不能排除距离或路由因素。
9. 评测有什么局限？八个模拟Case、一次运行、单个小模型、结构化问题；没有真实网络泛化证据和统计显著性结论。
10. 分工怎么解释？陈佩负责架构/Agent/模型，赵浩然负责工具/数据/评测/界面，各50%；两人都需理解以上内容并亲自复现。
