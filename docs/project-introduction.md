# FiberScope 项目介绍

作者：陈佩 23231203、赵浩然 23211256。

为校园网络维护者设计一个光纤链路时延诊断助手，帮助判断“光纤长度造成的传播下限”“传播以外的额外 RTT”和“测量数据错误”。课程综合项目沿用腾讯课堂表格中两人的通信链路分析与光纤时延方向，重新实现完整应用；课堂表格提供的是作业记录，并未提供旧源代码。

用户输入问题并选择链路，LLM 选择查询、计算、阈值检查三个工具中的必要部分。程序执行真实的 JSON 查询及数值计算，再以观测、两种假设、证据、结论与建议输出结果。测量记录均为明确标记的模拟场景。系统不扫描、不修改真实网络。

本次交付采用单 Agent 的受约束计划执行结构：Qwen3-0.6B 负责意图理解和工具选择；Python 负责参数来源、物理计算和证据归纳。没有使用 PydanticAI/CrewAI 运行时，而是用标准库实现容易审计的最小 Agent。架构保留本地模型 /v1 接口方式，便于以后更换模型。

项目新增：区分单程/RTT、低于传播下限的数据检查、业务预算判定、证据不足处理、可视化界面、八个测试 Case 和同模型对照实验。与原课堂“单次计算/分级工具”相比，形成了完整排障闭环。
