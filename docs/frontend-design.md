# 前端界面设计

页面由“发起调查”“Agent 工作过程”“证据与结论”三部分组成。左侧选择测试场景、模型模式、问题和业务预算，右侧逐条展示模型计划与真实工具日志。结论区显示单程传播下限、实测 RTT、额外 RTT，以及两个候选解释和下一步行动。

运行方式：`python -m src.web`，浏览器访问 http://127.0.0.1:8765 。

界面用明确标签区分 LLM 模式与非 LLM 离线演示；数据来源始终显示为模拟。请求失败直接呈现错误，防止误将空结果当正常。页面文本使用转义处理，避免将用户输入作为 HTML 执行。

场景包含正常、拥塞嫌疑、传播受限、缺失、矛盾、负长度、仅计算、仅阈值等八种。业务预算单位固定 ms；RTT 与单程指标在 Case 配置中明确，底层拒绝混用。

API：GET /api/cases 返回去除标准答案的场景；POST /api/run 接收 {request, mode}，返回模型计划、工具输入/输出、结论及耗时。服务仅绑定本机地址，不作为互联网生产服务。
